I've been a Java developer for about twenty five years, but will happily solve problems using Groovy, Python, Swift, Go, Bash, C or Assembly or any other tool if the project calls for it.

My main areas of expertise are Spring, CQRS with the Axon Framework, Java on Azure, and I'm comfortable with Jenkins at any scale. My core strengths are debugging, reading and understanding unfamiliar codebases, refactoring, upgrading legacy systems, and organizing code so it stays maintainable.

As much as I've enjoyed manual programming, I always do my best to stay up to date. I've built applications with Copilot CLI, Claude Code CLI, Junie as well as open source harnesses like OpenCode and T3Code as well as locally hosted open source models.

When I'm not programming, I can often be found trail running or cycling while listening to podcasts on natural sciences and space, or talking about dinosaurs with my kids.

I'm an EU citizen and permanent resident of the US, living in North Carolina.
